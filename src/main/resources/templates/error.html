Đã Xảy Ra Lỗi Hệ Thống

Hệ thống ghi nhận trạng thái lỗi khi xử lý yêu cầu của bạn

Mã trạng thái: 500
Lỗi: Internal Server Error
Chi tiết: Could not open JPA EntityManager / Database connection error
Cách khắc phục nhanh (Thường do kết nối CSDL):
  1. Khởi động lại SQL Server: Mở SSMS $\rightarrow$ Nhấp chuột phải vào tên Server ở thanh trái $\rightarrow$ Chọn Restart.
  2. Kiểm tra mật khẩu SA: Đối chiếu tài khoản và mật khẩu trong file src/main/resources/application.properties.
  3. Chạy lại ứng dụng: Chạy lại lệnh java -jar target/bookstore-chain-management-1.0.0.jar hoặc Run trong IDE.
